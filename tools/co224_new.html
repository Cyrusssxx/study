原码一位乘法：符号位单独异或，数值部分取绝对值相乘。

数值迭代（迭代式）：每轮看乘数最低位 yᵢ，先 P ← P + |X|·yᵢ，再把 [P:Y] 逻辑右移 1 位（操作的是绝对值，无符号，故用逻辑右移），共 n 轮。乘积占 [P:Y] 共 2n 位（X 存被乘数、P 存部分积、Y 存乘数）。

图：原码一位乘法：X / Y / P 三寄存器与 n 次迭代流程

乘法三件事：① 符号——原码乘把符号位单独异或，数值取绝对值相乘；Booth 则符号位直接参与运算。② 过程——按乘数位决定「加 |X| / 加 0」（Booth 看 yᵢyᵢ₋₁：01 加 [X]补、10 加 [−X]补、00/11 空操作），每次 [P:Y] 联合右移 1 位，把乘数的每一位都用完（原码数值位 n 位 → n 轮）。③ 溢出——两者结果都是 2n 位，但判据不同、标志也不同：无符号看高 n 位是否全 0（否则 CF=1），有符号看高 n 位是否为低 n 位的符号扩展（否则 OF=1）。

无符号乘法：X / Y / P 三个寄存器 + 计数器控制 n 轮迭代

每轮按 Y 最低位决定是否加 X，然后 [P:Y] 联合右移

n 轮后 [P:Y] 的 2n 位就是完整乘积。高 n 位（P）全 0 才说明乘积能装进 n 位。只要高 n 位非 0 就超出 n 位范围，置 CF=1——无符号的溢出标志是 CF，不是 OF。

补码一位乘法（Booth 算法）：增加辅助位 y₋₁（初始 0），按 yᵢyᵢ₋₁ 决定：01 → 加 [X]补

10 → 加 [−X]补；00 / 11 → 空操作

每次做 算术右移（高位补符号位，这一点与无符号乘法的逻辑右移不同）。判溢出：高 n 位 P 必须等于低 n 位 Y 的符号扩展——Y 最高位是 0 则高半应全 0，是 1 则高半应全 1。不等则 OF=1。

实现方式两种：移位-加（串行，n 轮迭代、每轮 1 次加/减 + 1 次右移，硬件省但慢）。阵列乘法器（组合逻辑一次算出，一个时钟周期完成，硬件量大）。

除法运算：

  • 无符号除法：试商法，余数寄存器 R 与商寄存器 Q 联合左移，被除数补成 2n 位后放 [R:Q]（高位补 0，n=32 时即 64 位），除数为 0 时产生除法异常（中断）。
  • 补码除法：被除数按符号扩展补成 2n 位（正数补 0、负数补 1）；
    商溢出只有一种情形——-2ⁿ⁻¹ ÷ (-1)（真值 +2ⁿ⁻¹ 超出 n 位补码范围），此时 OF=1。
  • 两个 n 位无符号数相除不会溢出（商一定 ≤ 被除数）；
    被除数为 0 则商为 0。
