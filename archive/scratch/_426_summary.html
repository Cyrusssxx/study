★ 4.2.6 重点总结：文件物理结构 · 全方位深度解析

本章核心地位：文件物理结构是文件系统的最高频考点之一，覆盖连续/链接/索引三种分配方式、插入删除访盘次数、最大文件长度计算、多级索引、位示图换算五大题型。下列内容须逐表吃透、逐公式能默写。

三、FCB 与 FAT 在各操作中发生的变化

FCB（File Control Block）每个文件一个，记录文件全部元数据；FAT（File Allocation Table）整张磁盘一张，记录每个物理块的下一块号。FAT开机加载到内存。

五、簇（Cluster）的实现与影响

簇是文件系统分配磁盘空间的最小单位，由 1 个或多个连续扇区组成（1簇 = 2^k 扇区）。在很多教材中"磁盘块 = 簇"；严格说簇是逻辑分配单位，块是I/O单位。

对象存放方式
普通文件以簇为单位分配；最后一簇未用满→内部碎片
目录文件本身也是文件，以簇分配，每簇放若干目录项
FAT表占用专用簇（卷头部，有备份）
簇大小权衡：小簇内部碎片小但FAT表大、加载慢；大簇管理开销低但小文件浪费严重（1B文件也占整簇）。

FAT3232KB2²⁸≈2.68亿≈8TB（实际限4GB−1，目录项32位记大小）
NTFS4KB（默认）2⁶⁴16TB（实际）

FAT表项含义：0=空闲；1~0x0FFFFFEF=下一簇号；0x0FFFFFFF=EOF；0x0FFFFFF7=坏簇。连续分配和索引分配不需要FAT（FAT仅用于空闲管理时可例外）。索引块字段：直接地址项 / 一级间接 / 二级间接 / 三级间接。

七、索引表块号字节数 & 最大文件长度计算（核心公式）

块号位数 = ⌈log₂(磁盘总块数)⌉；块号字节数 = ⌈块号位数/8⌉（实际常取4字节对齐）。

例：磁盘16GB，块4KB → 总块数=2²²，块号位数=22，字节数=⌈22/8⌉=3字节（实际取4字节）。每索引块块号数 s = 4096/4 = 1024。

分配方式最大文件长度公式上例数值（B=4KB,p=4,s=1024）
链接总块数 × B2²²×4KB = 16GB
索引（仅直接k项）k × Bk=10 → 40KB
索引（直接+一级间接）(k + s) × B(10+1024)×4KB ≈ 4.05MB
索引（+二级间接）(k + s + s²) × B≈ 4GB
索引（+三级间接）(k + s + s² + s³) × B≈ 4TB
经典Unix i-node（13个地址项）：0~9直接(10项)、10一级间接(1024)、11二级间接(1024²)、12三级间接(1024³)。合计 ≈ 1,049,642块 → ≈ 4GB（块4KB）。

九、目录文件与目录项

目录本质是特殊文件，内容是目录项数组。FAT中目录项含文件名+起始簇号+大小+时间等；Unix/Linux目录项仅存"文件名+inode号"，其余信息在inode中。

"所占磁盘块号"的值：对文件=第一个数据簇编号；对子目录=该子目录第一个簇编号；"."指向自身，".."指向父目录。

十、打开文件需要读多少磁盘块？

过程：①从根目录逐级查找（每级至少1次）→ ②找到目录项得起始块/inode号 → ③读FCB/inode（1次）→ ④读索引块（索引分配时1次）。

例：打开 /A/B/C/file.txt，每级目录占1块，单级索引 → 读根目录1+读A1+读B1+读C1+读inode1+读索引块1 = 6次；若已在缓存则降为0~1次。

十三、空闲空间管理：位示图及其他方法

方法原理优点缺点
空闲表法记录每段连续空闲区首块号+块数适合连续分配碎片多时表项爆炸
空闲链表法空闲块串成链实现简单遍历慢
位示图法每块对应1bit：0空闲/1已分配紧凑、可快速找连续区磁盘大时位图本身占空间
成组链接法每块记一组空闲块号，末组记下组Unix经典，适合大型实现较复杂
位示图核心公式（字长w位，块号b）：
字号 = b / w（整除）；位号 = b % w（取余）；
反算块号 = 字号 × w + 位号。
例（w=32）：块100→字号3、位号4（从0计：100=3×32+4）。
